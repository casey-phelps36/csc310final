# NHL Player Performance Dashboard

This project is an interactive data science dashboard that allows users to explore, visualize, and analyze NHL player performance data. The app supports both skaters and goalies, includes advanced filtering by season and team, and provides machine learning–based predictions for future performance.

---

## Tech Stack

- Python
- Streamlit
- pandas
- numpy
- Plotly
- scikit-learn
